## Slide 1. 문제 정의 + 제품 방향 — 60초

### PPT 화면 (2분할)

**좌측 — 발견한 문제 (AS-IS)**

- 헤드라인: **"데이터는 있었지만, 흐름이 끊겨 있었습니다."**
- 상상대로 서울 화면 캡처 (또는 개념 아이콘) 아래에 4개 단절 포인트:
  1. 답변 상태와 반복 수요가 분리
  2. 어떤 팀이 볼 안건인지 연결 없음
  3. 판단 근거(정책·민원·뉴스·통계)가 흩어짐
  4. 검토 결과를 다음 조치로 넘기는 흐름 없음
- 하단 원래 과제: `출산·양육 민원과 데이터 수집 → 정책 수요 도출`

**우측 — 유케이의 역할 (TO-DO)**

- 헤드라인: **"상상대로를 대체하지 않고 활용을 돕는 백오피스"**
- 3줄 요약:
  - 5개 출처를 통합하고
  - 담당 범위와 판단 근거를 연결하며
  - 다음 조치(보고서)까지 이어줍니다
- 새싹이 말풍선: **"흩어진 수요와 근거를 다음 조치까지 이어드릴게요."**

### 캡처 레퍼런스
- **좌측**: 상상대로 서울 사이트의 시민 제안 목록 화면 캡처 1장 (답변 상태만 보이는 단순 목록 느낌)
- **우측**: UKKKK 수요 현황 종합 화면의 상단 헤더(2단계 필터 + KPI 카드가 보이는 부분) 캡처 1장
- 두 캡처를 좌우로 놓고 가운데 화살표로 연결

### 대본
> 원래 과제는 출산·양육 민원과 데이터에서 정책 수요를 도출하는 것이었습니다.
> 그런데 실제 상상대로 서울 데이터를 확인하니 네 가지 단절이 보였습니다. 첫째, 답변 상태와 반복 수요가 분리되어 있었습니다. 둘째, 어떤 팀이 어떤 안건을 봐야 하는지 연결이 없었습니다. 셋째, 판단 근거가 되는 기존 정책·민원·뉴스·통계가 흩어져 있었습니다. 넷째, 검토 결과를 다음 조치로 넘기는 흐름이 없었습니다.
> 그래서 저희는 상상대로를 대체하지 않고, 이 네 가지 단절을 연결해 **시민 제안을 담당 범위·판단 근거·후속 조치로 이어주는 행정 의사결정 지원 백오피스**를 만들었습니다.
