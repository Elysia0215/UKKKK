## 4. 지역값 해석

원본 `district` 기준 특정 자치구가 기록된 제안은 20건이고 `미상`은 804건입니다. 그러나 804건 전체를 동일한 결측치로 볼 수 없습니다.

- 본문에 특정 자치구명이 직접 등장하는 후보: 49건
- 서울시 전체·전 자치구 등 광역 범위를 직접 명시한 제안: 5건
- 지역 범위 미확인: 750건

따라서 지역값은 `원본 특정 구 / 본문 특정 구 후보 / 서울시 전체 명시 / 범위 미확인`으로 분리해야 합니다. 지역 범위 미확인을 임의의 자치구로 채우지 않습니다.

## 6. 발표 시연 범위

`보육·돌봄 인프라`의 분석 가능 제안은 179건이며, 이 가운데 `가족건강팀`이 주관 또는 협조 후보로 포함된 제안은 20건입니다.

이 범위는 다음 이유로 시연에 적합합니다.

1. 전체 824건에서 정책 영역 179건, 실제 팀 관련 20건으로 후보 축소가 명확합니다.
2. 대분류와 실제 조직 필터가 서로 다른 의미임을 보여줍니다.
3. 팀이 주관뿐 아니라 협조 후보로 연결될 수 있음을 설명할 수 있습니다.
4. 20건은 목록·차트 드릴다운·보고서 반영을 시연하기에 지나치게 작거나 크지 않습니다.

## 7. 모델링·검증 해석

현재 엔진은 단일 감독학습 예측 모델이 아닙니다.

- 한국어 정규화와 도메인 유사어 통합
- 규칙·점수 기반 8대 계층 분류
- KR-SBERT 의미 유사도와 유사 제안 군집
- 시민 수요·정책 공백·시급성·실행가능성·근거 신뢰도 가중치
- 업무분장 원문과 제안 텍스트를 대조한 R&R 1·2·3순위 후보

따라서 현 단계의 검증 대상은 “모델 정확도 00%”가 아니라 다음과 같습니다.

- 동일 필터가 10개 화면의 모수에 일관되게 적용되는가
- 제안 ID에서 원문·정책·민원·뉴스·통계·R&R 근거를 추적할 수 있는가
- 0건, 초기화, 단일·다중 선택에서 종속 필터가 정상 복구되는가
- 원문 수집 실패와 정상적으로 짧은 원문을 구분하는가
- 보고서·CSV가 현재 선택 범위를 유지하는가

## 8. 한계와 후속 검증

- R&R 후보는 공식 배정 결과가 아닙니다.
- 가중치와 임계값은 운영 규칙이며 정답 라벨 기반 정확도 수치가 아닙니다.
- 정상 원문 승인은 현재 브라우저별 로컬 상태입니다.
- 실제 PDF·HWP 바이너리 생성, 공용 권한·감사 로그, 서버 데이터베이스는 운영형 고도화 범위입니다.
- 수집 시점이 다른 원천을 “실시간 최신값”으로 표현하지 않고, 기준일이 있는 적재 데이터로 설명합니다.
