데이터 분석 정의서

2026.07.23

1. 개요

1. 주제

: 상상대로 서울 시민 제안(426건) + 국민신문고 실시간 현장 민원(582건) + 몽땅정보통 서울시 공식 사업(322건) + 네이버 뉴스(1,145건) + 자치구 통계 Multi-API 융합 기반 8대 대분류 정밀 분류 및 R&R 부서 1·2·3순위 라우팅 의사결정 모델 설계

2. 개발 목표

: 흩어져 있는 자치구별 출산 통계(출생아수, 합계출산율), 보육시설 인프라 현황, 비정형 시민 정책 제안 텍스트, 실시간 민원 데이터를 하나의 대시보드에 결합 및 융합한다. 이를 통해 정책 담당자가 정책 공급 공백(Gap)을 데이터 기반으로 즉시 발견하고, R&R 주관 부서 자동 라우팅 및 1클릭 일괄 답변(Batch Reply) 공문 생성을 통해 행정 효율성을 단축시키는 실무 지원 시스템을 구축한다.

3. 개발 내용

:  핵심 데이터 분석 프레임워크는 다음 2가지 실증 관점으로 구성된다.

[수요 vs 공급 불균형 프레임] 시민이 로그인 후 의견을 제출하는 고마찰(High Friction) 제안 수치(수요)와 현행 몽땅정보통 322개 정책 수(공급) 간의 카테고리별 수급 불균형 비율을 '시민 체감 정책 공백 지수'로 정의.

[행정 답변 불균형 실증 관측] 공감 722건+댓글 470건이 달린 제안(서울의료원 공공난임센터 반대)은 부서 답변이 부재한 반면, 공감 4건짜리 질문(어린이집 입학연기)은 답변이 완료되는 등 부서별·담당자별 답변 기준 미비 실태를 규명하고, [미답변 모아보기] 및 [1클릭 일괄 답변 기안] 시스템으로 해소하도록 설계.

4. KPI 가설

: 정책 우선순위 점수(시민 요구 강도·정책 공급 공백·사회적 시급성·행정 실행 가능성·AI 분석 신뢰도의 가중합, 3장 참조)가 높은 군집일수록 실제 정책 공백(미해결·미커버 비율)이 크고 행정 조치 시급성이 높을 것이라는 가설을 세우고, 6대 학술 선행 연구(2장)에 근거해 3가지 가중치 방법론(기본/박미경2022/KICCE2023)으로 검증한다.

2. EDA 명세서

목표 및 목적

정책 공급 공백(Gap)을 데이터 기반으로 즉시 발견하고, 자치구별·카테고리별 시민 수요와 정책 공급 간 불균형을 정량화하기 위한 8대 대분류 탐색적 데이터 분석.

1) 데이터 준비

데이터 정의

상상대로 서울 시민 제안 — 426건(프론트엔드 로드용) / 824건(전체 수집분), JSON — frontend/src/data/mockProposals.json, data/final/proposals.json

국민신문고 실시간 민원 — 582건, JSON — frontend/src/data/civil_requests_all.json

몽땅정보통 정책 DB — 322건, JSON — frontend/src/data/classified_policy.json

네이버 API 및 NMF 뉴스 — 1,145건, JSON — frontend/src/data/news_all.json

자치구 통계 — 25개 구, mockData.ts 내 하드코딩 — 2025년 잠정 합계출산율(서울시 0.630명) 및 출생아/보육시설 현황

⚠ 주의: mongttang.json(824건)은 파일명과 달리 상상대로 제안 데이터이며, 몽땅정보통 정책 데이터는 classified_policy.json(322건)이 정본임.

데이터 획득 방법

상상대로 서울(시민 제안 API/웹 크롤링), 국민신문고(민원 API), 몽땅정보통(정책 크롤링), 네이버 뉴스 API, 자치구 통계(공공데이터·통계청)의 Multi-API 융합 수집 체계.

2) EDA

EDA 과정

8대 대분류 카테고리 체계로 시민 제안·민원·정책 텍스트를 정밀 분류(4-4)하고, 아래 텍스트마이닝 파이프라인(textMining.ts)으로 정제 후 분포·결측 현황을 탐색.

조사/어미 제거(normalizeKoreanWord): 조사 17종 + 접미사 12종 규칙 기반 제거

유사어 통합(SYNONYM_MERGES): 다둥이→다자녀, 임산부석→임산부배려석 등

불용어 사전(STOP_WORDS): '서울시', '해주세요' 등 59개 기능어 필터링

동음이의어 안전장치(AMBIGUOUS_DISTRICT_KEYWORDS): 수유/방학/구의 등 7개 키워드는 같은 구의 확실한 지명이 동반 출현할 때만 자치구 매칭 인정, 단독 매칭 시 0.5배 감점

자치구 추정 엔진(inferDistrict): 25개 자치구 대표 지명 키워드(120+개) 가중 점수로 자치구 추정, { district, score, keywords, solidCount } 구조로 근거 반환

3) 결론

EDA 결론

한계: 프론트엔드 로드용 426건 기준 84.5%(360건), 전체 수집분 824건 기준 97.6%(804건)의 시민 제안이 자치구 미상(서울시 전체 대상)으로 확인됨.

분석 기준점 전환: 지도·비교 차트의 핵심 비교 축을 '시민제안수' 대신 전수 검증된 공공 행정 지표(출생아 수, 보육시설 수, 합계출산율) 중심으로 개편해 왜곡 방지

미상 격리 토글 탑재: 자치구 목록 조회 시 미상 포함/제외를 실무자가 직접 선택

5원 데이터 융합 복원: 텍스트 지역 키워드 추출 + 몽땅정보통·통계청 등 5원 융합으로 결측치 보완

결측치 복원 실무자 검증 워크플로우(원문 펼치기/원문 링크 → 체크박스 선택 → 1클릭 반영)로 Human-in-the-loop 확정 프로세스 구현

대시보드 반영 시 유의점: 미상 데이터를 특정 구로 강제 매핑하거나 임의 분포시키면 통계적 형평성이 상실되므로, 반드시 미상/자치구 데이터를 격리한 상태로 시각화해야 함

KPI 확정

3장의 정책 공급 공백 점수 공식(0.6×미해결도 + 0.4×(100－정책 커버리지))과 3가지 가중치 방법론(기본/박미경2022/KICCE2023)에 따라 재계산된 우선순위 점수 순으로 군집을 정렬하여, 상위권 군집을 우선 조치 대상으로 확정한다.

3. 모델링 명세서

목표 및 목적

정책 실무자가 학술 연구 근거를 바탕으로 설계된 가중치 모델을 선택·적용하여, 정책 우선순위 및 공급 공백을 설명 가능한(explainable) 방식으로 산정하는 규칙 기반 스코어링 모델링.

1) 데이터 준비

데이터 정의

2장 EDA 명세서의 5개 원천 데이터(상상대로 제안, 국민신문고 민원, 몽땅정보통 정책, 네이버 뉴스, 자치구 통계)에서 파생한 군집별 변수 — 제안 수·추천 수·댓글 수(시민 요구), 미해결 비율·정책 커버리지(공급 공백), 민원 유입 속도·위기 키워드(시급성) 등.

데이터 획득 방법

2장과 동일한 Multi-API 융합 수집 데이터를 8대 대분류 및 57개 군집 단위로 재집계하여 사용.

2) 전처리

전처리 과정

textMining.ts 공유 유틸을 통한 한국어 텍스트 정제(조사/어미 제거, 유사어 통합, 불용어 제거, 동음이의어 안전장치, 자치구 추정)를 키워드 탐색기·결측치 복원·데이터 전처리 전 구간에 공통 적용.

담당자 피드백 기반 사전 자동 업데이트(applyFeedbackKeywords): 담당자 피드백(지역/분류 오매칭+맥락 메모)이 localStorage에 축적되면, 반복 오매칭 키워드를 AMBIGUOUS_DISTRICT_KEYWORDS에 자동 반영하는 Human-in-the-loop 품질 개선 파이프라인

3) 모델 생성 및 학습

모델링 목표

최종 우선순위 점수 = (시민 요구 강도×Wd) + (정책 공급 공백×Wg) + (사회적 시급성×Wu) + (행정 실행 가능성×Wf) + (AI 분석 신뢰도×Wc). 방법론 변경 시 57개 군집이 재계산 결과에 맞춰 내림차순으로 실시간 재정렬되는 것을 목표로 함.

타겟(Y) 정의 및 근거

회귀·분류 예측이 아닌 5개 요소 가중합 기반의 연속형 우선순위 스코어(설명 가능한 스코어링)로 정의. 근거: 6대 학술 선행 연구의 가설→테스트→실증검증→대시보드 이식 4단계 파이프라인(아래 표 참조).

학습 방법

ML 학습이 아닌, 학술 연구 근거 기반으로 고정 설계된 가중치를 사용. 정책 공급 공백 점수는 다음 하위 공식으로 별도 산정:

정책 공급 공백 점수 = 0.6×미해결도(unresolved) + 0.4×(100－기존 정책 커버리지)

미해결도: 클러스터 내 시민제안 중 '검토중'이거나 민원이 미해결로 남은 비율의 평균

정책 커버리지: 몽땅정보통 322개 사업 중 해당 분류에 실제 공급 중인 사업의 유효성 비율

사용 특성: 제안·추천·댓글 수(로그 스케일+최신성 가중), 민원 유입 속도, 위기·안전 키워드 가산점, 조례 제정 용이성·예산 규모(실행 가능성), 표본 크기·출처 다양성(신뢰도)

4) 검증

모델링 검증 방안

6대 핵심 학술·정책 연구([가설→테스트/분석기법→실증 검증→대시보드 이식 결론] 4단계 파이프라인)를 근거로 가중치 및 지표 설계의 타당성을 검증.

결과

배기련 외(2021, 디지털융복합연구): 대중 댓글 25,800건 텍스트마이닝·감성분석 → 체감 정책 장벽은 '주거·일가정양립'에 있음을 실증 → 주거·노동 갭 지수를 독립 지표로 분리

오신휘·김혜진(2020, 보건사회연구): 752편 메타분석 → 텍스트마이닝 기반 여론 추출이 설문 대비 예측력 우수 → SBERT+NMF 기반 본 시스템의 방법론적 정당성 확보

성낙일·박선권(2012, 한국인구학): 232개 시군구 다중회귀 → 보육 인프라 공급이 출생아 수에 유의미한 정(+)효과 → 자치구별 보육시설 수-민원 불균형을 공백 점수에 연동

육아정책연구소(KICCE, 2023): GIS 공간분석·형평성 모델링 → 공간거리 반영 형평성 모델이 자원배분 효율 개선 → 25개 자치구 인프라 히트맵 및 KICCE2023(공급공백 40%) 모델 탑재

국회예산정책처(NABO, 2025): 280개 유관사업 실태조사 → 사업 분절화로 통합 조율 채널 부재 규명 → R&R 1·2·3순위 자동 라우팅 및 팀별 답변율 대시보드 구축

박미경(2022, 한국가족자원경영학회지): MZ세대 설문·Borich/IPA 분석 → 주택지원·일가정양립 요구도 최상위 실증 → 공감수·시급성에 방점을 둔 박미경2022(시민요구 40%) 모델 반영

모델링 결과 및 인사이트

6개 학술 근거가 모두 대시보드 지표·알고리즘에 이식되어, 가중치 모델 변경 시 즉시 우선순위 재정렬이 가능한 설명 가능한(explainable) 의사결정 지원 구조를 확립함.

AI 정책 가설 자동 생성 엔진(getPolicyHypothesis): 군집 선택 시 실제 제안·민원·정책 건수를 대입해 학술 근거 결합 가설을 자동 생성 (수요 건수·공백 점수·신뢰도·근거 논문 수 4개 배지로 표출)

4단계 학술 실증 검증 모달(getAcademicEvidenceItems): 6대 논문 각각의 가설→테스트→결과→결론을 투명하게 공개

대시보드 반영 시 유의점: 미상(서울시 전체) 데이터가 84.5~97.6%에 달해 자치구 단위 가중치 계산 시 반드시 격리·복원 절차를 거쳐야 하며, 그렇지 않으면 특정 구에 왜곡된 우선순위가 배정될 수 있음
