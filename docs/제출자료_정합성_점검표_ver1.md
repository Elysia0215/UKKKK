## 4. 표현 금지·주의

- `source_missing` 16건을 모두 실제 내용 결측으로 단정하지 않습니다.
- 짧은 원문은 원문과 저장 본문이 동일하면 정상입니다.
- 필터 검증 통계는 5원 전체 규모 화면이 아니라 현재 제안 필터 범위 검증 화면입니다.
- 팀 필터는 주관 1순위만이 아니라 협조 2·3순위까지 포함합니다.
- 현재 화면의 팀은 11개이며 업무분장 원천 18개 행과 구분합니다.
- “실시간”은 화면 재계산을 뜻하며 원천 API의 실시간 수집을 뜻하지 않습니다.
- 업무시간 절감률, 추천 정확도, 정책 효과를 측정 완료한 성과처럼 제시하지 않습니다.
